# Delivery roadmap

Suggested sequencing, subject to staffing and discovery. All items are proposed.

| Milestone | Suggested window | Outcome | Exit evidence |
|---|---|---|---|
| M1 | Days 1–14 | Trustworthy baseline | Scorer separation, provenance, adversarial tests, portable build plan |
| M2 | Days 15–30 | User-first onboarding | Addressable docs, accessible example, validated import/reset/export |
| M3 | Days 31–60 | Scoped local execution | Real diff, path policy, approval binding, cancellation and events |
| M4 | Days 61–90 | Reproducible evaluations | Original rows, blind mapping, complete coverage, costs, verifier |
| M5 | Months 4–6 | Qualified release candidate | Recovery evidence, second adapter, accessibility review, support plan |

See `planning/roadmap.json`, `planning/roadmap.csv`, and `planning/ISSUES.md` for thirty work items with acceptance criteria. New tool-enabled experiments are separate protocols. No milestone clears the frozen historical candidate’s held state.
