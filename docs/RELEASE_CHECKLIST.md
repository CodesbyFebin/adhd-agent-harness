# Release candidate checklist

No checklist completion is implied by inclusion in this package.

- [ ] Exact source revision and artifact hashes recorded.
- [ ] Build verified in an isolated compatible environment; migration behavior reviewed.
- [ ] Deterministic, tool-boundary, cancellation and approval-replay tests passed.
- [ ] Accessibility journey verified with documented methods and remaining limitations.
- [ ] Public labels distinguish demo heuristics, original benchmark and new judge evidence.
- [ ] Original evaluation rows complete and protocol identities comparable for claimed comparisons.
- [ ] Zero blockers; correctness and safety within tolerance; weighted improvement established.
- [ ] Documentation capability claims match the implemented version.
- [ ] Privacy, deletion, export and provider disclosure verified.
- [ ] Maintainer support scope and security reporting path established.
- [ ] Release notes include failures, limitations and migration instructions.

The old candidate stays held regardless of this product release. A future release can qualify a separately identified candidate without modifying the historical board.
